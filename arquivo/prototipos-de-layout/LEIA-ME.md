# Protótipos de layout (arquivo)

As 6 versões de layout feitas em novembro de 2026 para o time escolher. **Não é o sistema em uso**: a versão escolhida (V6) virou o monitor em `web/` e evolui lá. Esta pasta fica só como histórico; nada aqui é atualizado.

- V1 a V5: escala de aderência ao manual da marca Sicredi (do manual 100% ao limite mínimo).
- V6 · Fila e execução: o rascunho do time, como estava em 15/11/2026.
- `prototipos/index.html`: página de comparação, com prints.

Para abrir:

```bash
cd arquivo/prototipos-de-layout
python3 -m http.server 8002
```

e acesse `http://localhost:8002/prototipos/`. As fontes ficam em `assets/fontes/` (cópia), para a pasta funcionar sozinha.
